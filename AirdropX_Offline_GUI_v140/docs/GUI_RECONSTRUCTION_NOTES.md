# GUI reconstruction notes

The uploaded RAR did not contain `main.py` or the `ui/` Python sources, but its surviving documentation identifies the original program as PyQt6 and names `main.py`, `ui/config_panel.py`, `ui/simulation_thread.py`, and `ui/monitor_panel.py`. The screenshot `original_gui_reference.png` was preserved in the archive and is used as the visual reference for this reconstruction.

The MATLAB GUI (`matlab/airdropx_gui.m`) is intentionally not used as the frontend. MATLAB is treated as the v1.4.0 simulation/control backend only.
