AirdropX Portable Windows x64

运行方式：
1. 解压整个 AirdropX_Portable_Windows_x64 文件夹。
2. 双击 启动AirdropX.bat，或进入 AirdropX 文件夹双击 AirdropX.exe。
3. 结果默认保存到：%USERPROFILE%\Documents\AirdropX\results

运行要求：
- Windows 10/11 x64。
- 不需要安装 MATLAB。
- 不需要安装 Python。
- 不需要安装 JSBSim。
- 不需要原始 AirdropX 源码目录。

说明：
本包是免安装版本，已经把 Python/PyQt6 运行时、JSBSim 原生运行库、MQ9_Reaper 飞机模型、Physics-MPC v1.3.6-Paper 控制器包线数据和 GUI 仿真程序放在一起。
如果 Windows Defender 或杀毒软件第一次扫描较慢，首次启动可能会等几秒。
