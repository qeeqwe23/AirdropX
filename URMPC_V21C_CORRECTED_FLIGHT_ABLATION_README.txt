UR-MPC v2.1C corrected-model-only nonlinear flight ablation
===========================================================

Purpose
-------
This stage intentionally does NOT add tube MPC. It changes exactly one causal variable relative to the v2.0.5 nonlinear flight baseline: the adaptive Plant A/B supplied to the existing single MPC are taken from the v2.1B corrected candidate bank.

Required preconditions
----------------------
The runner refuses to fly unless the independent v2.1B artifacts show:
- projected calibration validation 15/15 PASS
- corrected vertex preflight 55/55 PASS
- corrected cfg transitions 12/12 PASS
- candidate ur_meta.v21_deploy_ready = true

Unchanged
---------
- one existing MPC object
- Output/MV/MV-rate weights
- Np / ControlHorizon
- physical MV authority
- soft model-validity rate-trust constraints
- estimator policy stored in the v2.1B candidate (v2.0.5 static-white ablation baseline)
- mission/drop schedule
- no recovery, TECS, H-PI or cfg-specific tuning
- NO tube feedback and NO tube constraint tightening

Why before tube
---------------
The v2.1B corrected residual table contains p95 empirical envelopes. A p95 envelope is an audit statistic, not a deterministic hard support set for robust-invariant-set guarantees. More importantly, v2.1B changed the model itself and passed all offline gates. The clean next causal experiment is therefore to run the corrected model alone in the nonlinear mission before adding a second mechanism (tube feedback/tightening).

Run
---
PowerShell:
  .\run_urmpc_v21c_corrected_flight_D_temp.ps1

Default output
--------------
matlab/results/mpc_physics_v1/fixed_stability_urmpc_v21c_corrected_only/

The normal fixed_stability_summary.csv, V050/urmpc_controller_trace.csv and residual audit files are generated by the existing pipeline. An additional urmpc_v21c_experiment_manifest.csv records the candidate version and tube_enabled=false.

Decision after this run
-----------------------
1) If cfg2/cfg3 stability improves materially without tube, retain the corrected model and construct W only from corrected-model held-out residuals.
2) If the same slow divergence remains, do not further tune estimator/authority. Proceed to a separate v2.1D empirical-support + ancillary-feedback/tube-feasibility stage.
3) Do not call the current p95 table a deterministic robust W set.
